# Implementation Notes

## Current Status

The Sortez application is currently implemented as an **event listing application** that displays upcoming events in a timeline format.

## Data Structure

The application uses the following event data structure:

```json
{
  "id": 1,
  "name": "Event Name",
  "date": "2026-01-27",
  "time": "20:00",
  "lieu": "Paris, France",
  "description": "Event description",
  "link": "https://example.com",
  "count": 1,
  "created_at": "2026-01-27T12:00:00Z"
}
```

### Required Fields:
- `date` (YYYY-MM-DD format)
- `name` (event name/title)

### Optional Fields:
- `time` - Event time in HH:MM format
- `lieu` - Event location
- `description` - Event description
- `link` - URL to more information
- `count` - For future heatmap compatibility (default: 1)
- `created_at` - ISO timestamp
- `id` - Unique identifier (auto-generated by frontend)

## Files

- **index.html** - Main form for adding events
- **iframe.html** - Event listing display (can be embedded)
- **js/app.js** - Event form handling and localStorage management
- **data/events.json** - Event data storage
- **.github/workflows/add-event.yml** - GitHub Action for adding events

## Future Enhancements

The README mentions Cal-Heatmap integration which is not currently implemented. If adding heatmap functionality:
1. Add Cal-Heatmap library
2. Implement conversion function from events to heatmap data
3. Use `count` field for intensity
4. Consider adding `image` field for event thumbnails

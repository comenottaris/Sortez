Options de synchronisation GitHub (facultatif)

Si vous voulez que l'ajout d'événements mette à jour automatiquement un fichier `events.json` dans un repo GitHub, entrez ci-dessous un token personnel et les coordonnées du repo. Attention : stocker un token côté client est peu sécurisé — préférez une API serveur ou GitHub Actions avec secrets.

Le flux client utilisera l'API GitHub pour créer/modifier le fichier et déclenchera un `push` qui activera les workflows du repo.
